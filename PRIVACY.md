# Política de privacidad — Clonar en Drive

_Última actualización: 8 de octubre de 2026_

**Clonar en Drive** accede a tu Google Drive únicamente para ejecutar las copias que tú solicitas.

## Qué datos se usan

- **Archivos, carpetas y permisos de Google Drive**: se leen los nombres, la estructura y los permisos de los ítems que eliges clonar, y se crean las copias y permisos en el destino que indicas.
- **Pestaña activa de Google Drive**: al pulsar *Usar selección de Drive* se leen los identificadores de los ítems seleccionados en esa pestaña.
- **Token de acceso de Google**: lo gestiona Chrome (`chrome.identity`); la extensión no lo almacena.

## Qué no se hace

- No se envía ningún dato a servidores propios ni de terceros: la extensión no tiene servidor y solo se comunica con las API de Google.
- No se almacenan, venden ni comparten tus datos, ni se usan para publicidad o para entrenar modelos.
- No se recopilan analíticas ni telemetría.

El uso de la información recibida de las API de Google cumple la [Política de datos de usuario de los servicios de API de Google](https://developers.google.com/terms/api-services-user-data-policy), incluidos los requisitos de Uso Limitado.

## Revocar el acceso

Puedes revocar el acceso en cualquier momento desde <https://myaccount.google.com/permissions> o desinstalando la extensión.
